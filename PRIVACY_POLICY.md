# Privacy Policy

## 1. General Information

This project is a university demonstration application (Blackjack game) created for educational purposes.

The application does not collect, store, or transmit personal data to external servers.

## 2. Cookies and Local Storage

The application may use local storage to remember user preferences (such as consent to cookies).

No tracking, analytics, or third-party cookies are used.

## 3. Data Processing

No user accounts are required.
No personal information is requested.
No data is shared with third parties.

## 4. User Rights (GDPR)

Since no personal data is processed externally, there is no data storage beyond the local browser environment.

Users may clear their browser data at any time.

## 5. Limitations of Use

This project is intended for educational purposes only.
It is not a real gambling service.
It does not involve real money transactions.
