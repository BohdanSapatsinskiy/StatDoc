# 🎴 Blackjack Game

## 📌 Project Description

This is a web-based Blackjack game built with **React** and **TypeScript**.  
The project demonstrates component-based architecture, custom hooks, context API, routing, form handling, and automatic documentation generation using **TypeDoc**.

---

## ⚙️ Technologies Used

- React
- TypeScript
- Vite
- React Router
- Formik
- Yup
- TypeDoc

---

## 📂 Project Structure

```
src/
 ├── components/   # Reusable UI components
 ├── pages/        # Application pages
 ├── hooks/        # Custom React hooks
 ├── context/      # Global state (Context API)
 ├── assets/       # Images and static files
 └── main.tsx      # Application entry point
```

---

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Build project

```bash
npm run build
```

### Generate documentation

```bash
npm run docs
```

Documentation will be generated in the `./docs` folder.

---

## 📘 Documentation

Documentation is generated using **TypeDoc**.

Configuration file:

```
typedoc.json
```

To regenerate documentation:

```bash
npm run docs
```
